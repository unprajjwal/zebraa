# Zebraa Desktop App (Tauri 2)

This crate (`zebraa-app`) contains the Tauri 2 backend and configuration for the Zebraa desktop application.

## Packaging & Build Targets

Target outputs configured in `tauri.conf.json`:
- **macOS**: `dmg`, `app`
- **Windows**: `nsis`
- **Linux**: `appimage`, `deb`

These match the original Electron targets configured in `apps/desktop/electron-builder.yml`.

### Additional Target Handling

#### 1. macOS Plain Zip (`.app.zip`)
Tauri's native bundler produces `.app` bundles and `.dmg` installers. To produce a plain `.zip` archive of the `.app` bundle (matching electron-builder's `mac.target: zip`):
- Run `./scripts/package-mac-zip.sh` after `tauri build`.
- This script compresses `target/release/bundle/macos/Zebraa.app` into `Zebraa-macOS.zip`.

#### 2. Windows Portable Executable
Electron-builder supports `win.target: portable`. For Tauri applications on Windows:
- **Standalone Binary (Standard)**: Tauri compiles the app into a self-contained native binary at `target/release/zebraa-app.exe`. Because Tauri apps link against system WebView2 (built-in on Windows 10 and 11) and bundle all static frontend assets, `zebraa-app.exe` functions directly as a portable standalone executable. It can be distributed as-is or packaged into `Zebraa-portable-windows.zip`.
- **NSIS Portable Installer**: Alternatively, NSIS installers generated by Tauri can be built using custom NSIS definitions or flags if portable installer extraction is preferred.
